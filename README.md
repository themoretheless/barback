# barback

CLI-календарь на Rust.

## Возможности

- События с длительностью и повторами: `none`, `daily`, `weekly`, `monthly`
- Виды: день, неделя, месяц (с пометкой занятых дней), agenda
- Предупреждение о пересечении событий при добавлении
- Хранение в `barback.json` (в текущей директории)

## Использование

```
barback add <ГГГГ-ММ-ДД> <ЧЧ:ММ> <минуты> <название> [none|daily|weekly|monthly]
barback rm <id>
barback day [ГГГГ-ММ-ДД]
barback week [ГГГГ-ММ-ДД]
barback month [ГГГГ-ММ-ДД]
barback agenda [дней]
```

Пример:

```
barback add 2026-08-06 10:00 60 Стендап команды weekly
barback week 2026-08-06
```

## План

1. Юнит-тесты: `occurrence_on` (повторы, конец месяца), `overlaps`, парсинг аргументов
2. Команда `edit` для изменения события без пересоздания
3. Повтор `monthly`: перенос 29-31 числа на последний день короткого месяца вместо пропуска
4. Экспорт/импорт `.ics`
5. Естественно-языковой ввод даты («завтра в 13»)
6. Исключения из серии повторов
7. Напоминания через системные уведомления

Полный бэклог идей - в [IDEAS.md](IDEAS.md).
