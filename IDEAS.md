# Бэклог идей

Оставшиеся фичи из брейншторма. Уже реализовано: базовые виды (день/неделя/месяц/agenda), простые повторы (daily/weekly/monthly), предупреждение о пересечениях, JSON-хранилище.

Ближайший план - в [README.md](README.md#план).

## Виды и навигация

- Мини-календарь для быстрого перехода по датам
- Бесконечная прокрутка месяцев
- Переход к дате естественным языком («через 2 вторника»)
- Компактный режим «только занятые дни»
- Вид «3 дня» для мобильных
- Timeline-шкала дня с масштабированием
- Режим «фокус на сегодня»

## Создание событий

- Быстрое создание строкой естественного языка («обед с Аней завтра в 13»)
- Drag-and-drop для создания и растягивания событий
- Шаблоны событий (стендап, 1:1, тренировка)
- Дублирование события в один клик
- Голосовой ввод
- Создание события из письма/сообщения (парсинг текста)
- Создание события из фото афиши (OCR)
- Черновики событий

## Повторения

- Гибкие правила (каждый 2-й четверг месяца, кроме праздников)
- Исключения из серии без разрыва серии
- Повтор «через N дней после завершения предыдущего»
- Автоперенос с выходных на будни
- Окончание серии по счётчику или дате
- Сезонные события (только зимой)
- Monthly для 29-31 числа: перенос на последний день короткого месяца

## Напоминания

- Многоступенчатые (за неделю, за день, за час)
- С учётом времени в пути (по картам/пробкам)
- «Пора выходить из дома»
- Умный snooze («напомни после текущей встречи»)
- По геолокации («когда буду рядом с магазином»)
- Настраиваемые звуки/вибрации по типу события

## Совместная работа

- Общие календари семьи/команды
- Опрос по времени встречи (аналог Doodle)
- Ссылки для самозаписи (аналог Calendly)
- Free/busy занятость коллег без деталей
- Делегирование управления календарём
- Комментарии внутри события
- RSVP со статусами («может быть, приду позже»)
- Автопоиск слота для группы людей
- Приглашения внешним участникам по email
- Роли: организатор, соорганизатор, участник

## Интеграции

- Синхронизация Google / Outlook / iCloud / CalDAV
- Импорт/экспорт .ics
- Автовставка ссылок на видеозвонки (Zoom/Meet)
- Интеграция с задачниками (Todoist, Things, Linear)
- Погода в сетке дня
- Праздничные календари стран
- Расписания спортивных команд по подписке
- Вебхуки и публичное API
- Интеграция с трекерами привычек
- Подписки на публичные календари

## Умные функции

- Автораскладка задач в свободные слоты (time blocking)
- Защита фокус-времени от бронирования
- Предложения переноса при конфликте
- Умные буферы между встречами
- Аналитика времени (встречи/спорт/семья)
- Предложение отменить встречи с низкой посещаемостью
- Автосуммаризация недели
- Предсказание длительности по истории
- Рекомендация лучшего времени для задач
- Дедлайн-трекер с обратным отсчётом

## Часовые пояса и путешествия

- Двойная шкала часовых поясов
- Планирование с участниками из разных зон
- Автоподстройка при перелёте
- «Местное время» vs «фиксированное время»
- Автовставка рейсов из билетов

## Персонализация

- Цветовые схемы, раскраска по календарям/тегам
- Свои иконки/эмодзи для типов событий
- Настраиваемое начало недели и рабочие часы
- Тёмная тема, высококонтрастный режим
- Виджеты на рабочий стол/экран блокировки
- Кастомные поля события (бюджет, ссылка, чек-лист)
- Плотность интерфейса: компактно/просторно

## Особые типы событий

- Дни рождения с возрастом и напоминанием о подарке
- Годовщины и памятные даты
- Многодневные события и отпуска («меня нет»)
- Трекинг циклов (сон, тренировки, здоровье)
- Tentative-слоты («может быть»)
- События без времени («когда-нибудь в марте»)
- Чек-листы внутри события
- Прикрепление файлов и ссылок

## Приватность и надёжность

- Приватные события, видимые как «занят»
- Сквозное шифрование
- Офлайн-режим с синхронизацией
- История изменений («кто перенёс встречу?»)
- Корзина удалённых событий
- Резервные копии и полный экспорт

## Необычное

- «Машина времени»: моя неделя год назад
- Годовой heatmap занятости (как GitHub-контрибуции)
- Заметки постфактум к прошедшим событиям
- Шаблон «идеальной недели»
- Совместный обратный отсчёт до события
- Гибрид календарь+канбан для дедлайнов
- Дневник: план vs реальность
- Ретроспектива месяца с инсайтами
- Геймификация: серии без пропусков
- Печать недельного разворота в PDF
- Ассистент на естественном языке («освободи мне пятницу»)
- Свободные слоты текстом в буфер обмена
- Pomodoro, привязанный к слотам
- Автопланирование поездок: событие + дорога + парковка
- «Тихие часы»: авто-DND во время событий
- Балансировка жизни: предупреждение о перекосе в работу
